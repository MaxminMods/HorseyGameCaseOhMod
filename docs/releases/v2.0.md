# CaseOh90000 v2.0 - Friendlier Direct DNA and Repo Cleanup

This release makes Direct DNA the clear main workflow, adds DNA locks for pasted SIM results, and cleans up the repo layout for players and future coding work.

## Highlights

- Direct DNA Editor is now the preferred tab order.
- Fast-open buttons for Speed H18, Wheels H01/H08/H09, Tail H07/H02, and Timing H19.
- Collapse all button for the helix editor.
- Lazy helix rendering kept so the panel opens quickly.
- DNA presets and manual base edits can be remembered as DNA locks for pasted SIM results.
- The panel remembers Direct DNA text, preset choices, strand choices, window options, and active DNA locks.
- Player instructions are simpler, with Codex/developer notes moved under `docs/`.

## Safety

- Does not include Horsey Game, `Horsey.exe`, game assets, or save files.
- Patches a copied branch, not your normal Steam install.
- Streamer path hiding remains on by default.
