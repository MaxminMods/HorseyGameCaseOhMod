# HorseyGameCaseOhMod v2 - Friendlier Direct DNA and Repo Cleanup

This release makes Direct DNA the clear main workflow, adds DNA locks for pasted SIM results, and cleans up the repo layout for players and future coding work.

## Highlights

- The panel now opens in the default order Parameters, Intensity, Gene Lab, Direct DNA, Settings.
- Tabs now have colored borders: red Parameters, orange Intensity, green Gene Lab, blue Direct DNA, and gray Settings.
- Tabs now include small unique icons so each area is easier to spot.
- Main tabs now sit directly under the header instead of below privacy/hotkey controls.
- Larger default fonts and wider default window size make the panel easier to read.
- Tabs can be dragged into a custom order, and the order is remembered.
- Dense SIM slider sections use columns to reduce scrolling.
- Horsey is automatically fit into a non-fullscreen side-by-side layout with the panel when both are open.
- The SIM9000 `G:x/total` readout can mirror the chosen generation total when experimental search controls are enabled.
- First-run setup now keeps the detected/default paths, opens the panel by default, and skips desktop shortcut creation when pressing Enter.
- Download/release zips now open to the start launcher, panel launcher, README, and one app folder.
- Launchers now show a clear Python 3 + Tkinter install message if the panel cannot start.
- Fixed a font-style parsing issue that could prevent the panel window from opening.
- Fast-open buttons for Speed H18, Wheels H01/H08/H09, Tail H07/H02, and Timing H19.
- Collapse all button for the helix editor.
- Lazy helix rendering kept so the panel opens quickly.
- DNA presets and manual base edits can be remembered as DNA locks for pasted SIM results.
- The panel remembers Direct DNA text, preset choices, strand choices, window options, and active DNA locks.
- Player instructions are simpler, with Codex/developer notes moved under `docs/`.

## Safety

- Does not include Horsey Game, `Horsey.exe`, game assets, or save files.
- Patches a copied branch, not your normal Steam install.
- Streamer path hiding remains on by default.
- All mods are used at your own risk; this tool is intended to be as safe as possible, but there can never be guarantees.
