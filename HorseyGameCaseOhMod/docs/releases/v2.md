# HorseyGameCaseOhMod v2 Release Notes

HorseyGameCaseOhMod v2 focuses on making the panel easier to use, making Direct DNA the main workflow, and keeping releases cleaner for new players.

## Panel and Layout

- Renamed the main tabs to **Parameters**, **Intensity**, **Gene Lab**, **Direct DNA**, and **Settings**.
- Added stronger tab borders, unique icons, and a remembered drag-to-reorder tab layout.
- Moved the main action buttons above the tabs and gave them distinct colors.
- Increased default font sizing and panel width for better readability.
- Reduced scrolling by arranging dense SIM controls into columns.
- Added automatic side-by-side window fitting for Horsey and the panel.
- Detached the panel launchers so an extra command window does not stay open.

## SIM9000 Controls

- Added live generation and race-slot updates when **Apply to running game** can safely find the active SIM9000 state.
- Updated the in-game `G:x/total` and `R:x/total` readouts to match the selected generation and race-slot settings.
- Relabeled gene-pool controls as horses/race slots so the visible race totals are easier to understand.
- Kept the proven baseline restore flow available from the panel.

## Direct DNA

- Made Direct DNA the recommended workflow for exact `A`, `T`, `C`, and `G` edits.
- Added DNA locks for keeping selected bases while applying them to pasted SIM result DNA.
- Added fast-open buttons for common helix groups: speed, wheels, tail, and timing.
- Added Collapse all for the expanded helix editor.
- Kept helix controls lazy-loaded so the panel opens quickly.
- The panel now remembers DNA text, preset choices, strand choices, window options, and active DNA locks.

## Caseoh Arena

- Renamed the old Abandoned Track to **The Caseoh Arena** in the copied branch.
- Added a 40-furlong arena race option.
- Added branch-only garage sign art.
- Added the native in-game arena timer runtime, guarded so it only runs in the copied branch.
- The arena timer starts from Horsey's real race-start sound and stops on the first finish sound.
- Reset now keeps the last race result visible until the next race starts or the player leaves the arena.
- Renamed the old **Bio-Hacker** map label to **CaseohHaus**.

## Packaging and Safety

- Release zips open to the start launcher, panel launcher, README, and one app folder.
- First-run setup defaults to the detected Horsey path, the default save location, no desktop shortcut, and automatic panel launch.
- Launchers now show a clearer Python 3 + Tkinter message if the panel cannot start.
- Public releases are kept free of Horsey Game files, `Horsey.exe`, saves, copied branches, logs, and local path config files.
- All changes are designed for the copied branch, not the normal Steam install.
