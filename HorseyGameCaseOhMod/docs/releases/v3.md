# HorseyGameCaseOhMod 3.0 Release Notes

HorseyGameCaseOhMod 3.0 is focused on easier setup, a cleaner panel, stronger SIM9000 controls, Direct DNA usability, and the separate CaseOh parallel dimension.

## Highlights

- Top-level download folder now starts with the README, Start Here, Launch Panel, Play CaseOh Horsey, and one app folder.
- Start Here automatically creates the CaseOh parallel dimension, hides paths for streaming, starts Horsey, and opens the panel when Horsey Game can be found.
- Normal play opens the existing CaseOh dimension instead of rebuilding over saves.
- Panel layout is larger, clearer, and easier to navigate.
- SIM9000 controls now cover parameters, intensity, generations, horses, race slots, and matching in-game totals.
- Direct DNA includes exact base editing, DNA locks, and saved editor choices.
- Caseoh Arena adds the 40-furlong race, sound-triggered timer, longer race music, garage sign art, and the **CaseohHaus** map label.
- Native runtime code was cleaned up and kept CaseOh-specific.
- Release packages exclude game files, saves, logs, local configs, and CaseOh dimension folders.

## Upgrade Notes

Extract the new download into a fresh folder and run `00_START_HERE_CaseOh90000.bat`. The mod will build a fresh CaseOh parallel dimension from the current local Horsey Game install.

All changes are intended for the CaseOh dimension, not the normal Steam install.
