# Changelog

## 3.0 - CaseOh Parallel Dimension Update

- Cleaned up first-run setup so new users can start from the top-level **Start Here** file.
- Simplified the release folder to the README, launchers, and one app folder.
- Normal play now opens the existing CaseOh parallel dimension instead of rebuilding over it.
- Refreshed the panel with larger text, colored tabs, saved layout options, and clearer action buttons.
- Improved SIM9000 controls for parameters, generations, horses, race slots, and live display totals.
- Made Intensity controls always available and removed the old experimental master checkbox.
- Improved Direct DNA editing with DNA locks and saved editor choices.
- Added Caseoh Arena support, including the 40-furlong race, arena timer, longer music, garage sign art, and **CaseohHaus** map label.
- Removed excess native runtime code.
- Tightened release hygiene so public packages exclude game files, saves, logs, local configs, and CaseOh dimension folders.

## Earlier Updates

- Added the Direct DNA editor for exact `A`, `T`, `C`, and `G` edits.
- Added streamer privacy/path hiding.
- Added exploding finisher tools and baseline restore support.
